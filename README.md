# Blanzy Cinco – Portfolio

Personal portfolio of Blanzy Gwynneth Faith N. Cinco, 4th-year BSIT Business Analytics student at José Rizal University.

Live site: https://leaveitto.github.io

## Structure

- `index.html` – landing page: intro, featured projects, about, skills, leadership, honors, contact
- `coursework.html` – other analytics coursework, grouped by year
- `assets/` – stylesheet, profile photo, dashboard screenshots
- `files/` – public resume and project reports (PDF), plus one Excel workbook

Plain HTML and CSS, no build step. Hosted on GitHub Pages.
